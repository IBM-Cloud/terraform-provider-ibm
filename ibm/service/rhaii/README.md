# Terraform IBM Provider Red Hat AI Inference
<!-- markdownlint-disable MD026 -->
This area is primarily for IBM provider contributors and maintainers. For information on _using_ Terraform and the IBM provider, see the links below.

A Red Hat AI Inference (RHAII) project is a resource controller instance of the `instructlab` service. The resource and data source in this package reuse the resource controller implementation and add RHAII specific attributes such as `project_id` and `endpoint`.
